Keyboard shortcuts

Click Add, then press the key combination, or tap Shift, Ctrl, Alt or ⌘ twice for a double tap. Keys are matched by their position on the keyboard, not by the character they type. A shortcut without Ctrl, Alt or ⌘ is ignored while you type in a field.

Search

The operator a text column starts with on a table's Search tab. phpMyAdmin itself always starts with LIKE, which only finds exact matches unless you type the % yourself.

Default operator for text columns

Column types that start on LIKE %...%. Every other column keeps phpMyAdmin's default. A type matches without its length: varchar covers varchar(255).
